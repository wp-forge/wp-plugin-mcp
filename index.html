Let your AI assistant work on your WordPress site

WordPress MCP gives Claude, Cursor and other MCP clients a secure Model Context Protocol endpoint for your site, with 52 tools for content, media, users, plugins, themes and more.

Download latest release View on GitHub

Built for real site work

One endpoint at /wp-json/mcp/wp-forge, built on the WordPress Abilities API and the official MCP adapter.

52 ready-to-use tools

Search and edit content, upload media, and manage users, comments, settings, plugins, themes and global styles from your AI assistant.

Respects WordPress permissions

Every tool checks the capabilities of the user it runs as. Sensitive tools, such as the error log and WP-CLI, need dedicated capabilities that only administrators get by default. WP-CLI is also off until you enable it.

Application Password auth

Connect with a standard WordPress Application Password. No extra accounts or services, and you can revoke access from your profile at any time.

Optional activity log

Record which tools ran, who ran them, the result and how long they took. Tool arguments and responses are never logged.

Full REST API access

Discover any REST route on your site, including routes added by other plugins, and call it through a single tool.

Updates from GitHub

New releases appear in your WordPress dashboard like any other plugin update, with support for automatic updates.

Set up in a few minutes

You need a WordPress site you can install plugins on, and an MCP client such as Claude Desktop or Cursor.

  1. Install the plugin Download the latest zip, then upload it under Plugins → Add New → Upload Plugin and activate it.
  2. Create an Application Password Go to Users → Profile → Application Passwords and create one for your MCP client.
  3. Add the server to your client Paste the configuration below into your MCP client, with your site URL, username and password. 
{
  "mcpServers": {
    "wordpress": {
      "command": "npx",
      "args": [
        "-y",
        "@automattic/mcp-wordpress-remote"
      ],
      "env": {
        "WP_API_URL": "https://example.com/wp-json/mcp/wp-forge",
        "WP_API_USERNAME": "YOUR_WORDPRESS_USERNAME",
        "WP_API_PASSWORD": "YOUR_APPLICATION_PASSWORD",
        "OAUTH_ENABLED": "false"
      }
    }
  }
}

After activating the plugin, Settings → WordPress MCP shows this configuration with your site’s URL already filled in.
